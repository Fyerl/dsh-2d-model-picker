# Code of Conduct

This project follows [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

Be welcoming and respectful, and focus feedback on the work. Harassment, discrimination, and personal attacks are not acceptable. Maintainers may remove inappropriate content and restrict repeat offenders.

Contact the maintainer through GitHub to report a concern. Avoid posting sensitive information in public issues.
